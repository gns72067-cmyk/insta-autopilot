# insta-autopilot

인스타그램 카드뉴스·10초 릴스를 **내 PC 의 Claude** 가 만들고 올려 주는 Claude Code 플러그인입니다.
**주제만 고르면** 조사·팩트 시트 → 훅 → 사진 → 카드 → 릴스 → 캡션까지 자동으로 만들고, **검토 화면(웹)** 에서 한 번에 보고 고친 뒤 업로드 버튼으로 올립니다.
휴대폰에서도 검토 화면을 열 수 있습니다(밖에서 보기: 아래 3-1).

> **핵심 규칙은 규칙 서버에서 수시로 업데이트됩니다.** 글쓰기 기준·카테고리·템플릿·업로드 화면 절차는 플러그인에 들어 있지 않고,
> 작업을 시작할 때마다 규칙 서버(`https://rules.sonicent.co.kr`)에서 받아 **전자서명을 검증한 뒤에만** 적용합니다.
> 규칙이 바뀌면 작업 시작 때 "규칙이 X 로 업데이트됨: …" 한 줄로 알려 드립니다. 서명이 맞지 않는 규칙은 절대 쓰지 않고, 서버에 닿지 않으면 마지막으로 검증된 규칙으로 진행합니다.

- 조사·글쓰기는 Claude, 뉴스 수집·검사·렌더링은 플러그인 스크립트가 **내 PC 에서** 합니다.
- 설정·브랜드 이미지·결과물·토큰·수정 기록·성과는 **내 PC 에만** 저장되고 외부로 보내지 않습니다.
  (예외: 사진 검색 때 Wikimedia 에 보내는 연락처 이메일, 방식 B 업로드 때 Meta 로 보내는 영상·캡션)

---

## 1. 설치

필요한 것: Claude 데스크톱 앱(또는 Claude Code), Python 3.11+, ffmpeg.

```text
/plugin marketplace add gns72067-cmyk/insta-autopilot
/plugin install insta-autopilot@insta-autopilot
```

**업데이트** — 규칙은 작업할 때마다 자동으로 받습니다. 플러그인(기능) 업데이트는:
- 한 번만 켜 두기(추천): `/plugin` → **Marketplaces** → insta-autopilot → **Enable auto-update** (기본은 꺼짐)
- 또는 Claude 에게 "플러그인 업데이트해줘" → 끝나면 입력창에 `/reload-plugins` (또는 새 세션)

실행 환경 설치 (한 번):

```powershell
powershell -ExecutionPolicy Bypass -File "<플러그인 폴더>\setup.ps1"     # Windows (ffmpeg 까지: -InstallFfmpeg)
```
```bash
bash "<플러그인 폴더>/setup.sh"                                            # macOS / Linux
```

setup 은 데이터 폴더 안 `.runtime/venv` 에 파이썬 패키지와 Chromium 을 설치하고 점검(doctor)까지 합니다.
플러그인을 업데이트·재설치해도 데이터 폴더는 그대로 남습니다.

## 2. 셋팅 마법사

Claude 에게 **"인스타 셋팅해줘"** 라고 하면 차례로 묻습니다.

1. 환경 점검 → 2. 데이터 폴더 위치(기본 `문서/InstaAutopilot`) · 사진 검색용 **본인 이메일**
3. 카테고리(메인 1 + 서브 최대 2, 목록에 없으면 직접 입력) → 4. 핸들·표시 이름·**별칭**·브랜드 색·로고·캐릭터
5. CTA 문구 → 6. 제외 키워드·추가 RSS·말투 예시(과거 캡션) → 6-1. **업로드 방식**
7. 샘플 카드·CTA 확인 후 저장 → 8. 계정 추가 → 8-1. **검토 화면을 어디서 볼지**(이 PC / 밖에서 휴대폰 / 같은 Wi-Fi) → 9. **매일 아침 예약 작업**

계정을 추가하려면 마법사를 다시 실행하면 됩니다.

### 처음 쓰는 분 — 확인 순서 (꼭 이 순서로)

플러그인은 **매일 실제로 작업할 본인의 메인 PC** 에 설치합니다. 결과물·설정·토큰·예약 작업이 모두 그 PC 에 남습니다.

1. **환경 점검**: setup 스크립트 마지막 `doctor` 에서 필수 항목이 모두 ✔ 인지 확인.
2. **셋팅 마법사**: 본인 이메일(사진 검색용), 계정, 업로드 방식(A/B/C)까지 입력. 샘플 카드가 브랜드 색대로 나오는지 확인.
3. **첫 작업은 리허설**: 평소처럼 진행하다가 업로드 단계에서 "드라이런으로 해 줘".
   - 방식 A: Claude 가 브라우저에서 **로그인된 계정이 대상 계정인지** 확인하고, 파일을 올린 뒤 **캡션 입력 직전에 멈추는지** 봅니다(게시되지 않음).
   - 방식 B: 먼저 `ig_api me <핸들>` · `ig_api limit <핸들>` · `tempurl test <아무 mp4>` 가 모두 ✔ 인지 확인.
4. **실제 업로드 1회는 테스트 계정으로**: 서브 계정(또는 비공개 계정)으로 한 번 올려 보고, 게시물 URL 이 `meta.json` 과 `accounts/<핸들>/upload_history.jsonl` 에 기록되는지 확인. 그다음 실제 계정을 씁니다.
5. **아침 예약 작업**은 이 확인이 끝난 뒤, 매일 켜 두는 메인 PC 에서만 등록합니다(셋팅 마법사 9단계).

## 2-1. 매일 쓰는 법 (빠른 모드)

1. Claude 에게 **"오늘 이슈로 인스타 만들어줘"** (아침 예약 작업을 켜 두면 추천이 미리 와 있습니다)
2. 추천 목록에서 **번호만 고릅니다** — 계정이 여럿이면 `시사: 1,3 / 연애: 2`
3. Claude 가 끝까지 만든 뒤 **검토 화면 주소**를 알려 줍니다. 열어서:
   - 카드·릴스 미리보기, 그리드(프로필 썸네일) 확인
   - 훅 3버전 중 바꾸기 / 문구 직접 고치기 / 사진 후보 바꾸기 / 템플릿 A·B·C → **카드만 몇 초 만에** 다시 렌더
     (릴스는 릴스 탭에서 '릴스 만들기'를 누르거나, 확정·업로드할 때 자동으로 다시 만듭니다 — 약 40초)
   - 캡션 고치고 **캡션 확정** → **이대로 확정** → **업로드…** (확인창에서 계정·시각을 보고 한 번 더 누름)
4. 채팅으로 "훅 더 세게 다시 써 줘", "사진 다른 걸로 찾아 줘" 처럼 말해도 됩니다.

단계마다 직접 고르고 싶으면 "단계마다 확인할게" 라고 하면 예전 방식으로 진행합니다.

## 3. 출력 폴더 · 리모트 접근

```
InstaAutopilot/
├─ config.yaml                     규칙 URL, 채널, 승인 모드, 동시 렌더 수, 연락처, 임시 공개 URL
├─ accounts/<핸들>/                 profile.yaml, assets/, library/, style_examples.md,
│                                   edit_log.jsonl(캡션 수정 기록), upload_history.jsonl, performance.jsonl
├─ library/                        내가 찍었거나 권리가 있는 사진 (+ 같은 이름 .yaml 에 owner)
└─ output/<날짜>/
    ├─ briefing.md  status.md  review.html  batch.json
    └─ <핸들>/<번호>_<슬러그>/       factsheet.json/.md, hooks.json, card.png, card_grid.png, card_guide.png,
                                    reel.mp4, caption.txt, credits.txt, meta.json
```

메인 PC 에서 Claude 리모트를 켜 두면 밖에서도 폰으로 채팅을 이어 갈 수 있습니다. 결과물은 검토 화면(3-1)으로 보는 게 편합니다.
캡션은 채팅으로 수정본을 보내도 되고, PC 에서 `caption.txt` 를 직접 고친 뒤 "완료"라고 해도 됩니다(업로드는 항상 파일 최신본).

## 3-1. 검토 화면 · 밖에서 보기

검토 화면은 **내 PC 에서 도는 작은 웹 서버**입니다. 결과물을 외부 서버에 올리지 않습니다.

| 범위 | 어디서 열리나 | 켜는 법 |
|---|---|---|
| 이 PC 만 (기본) | 이 PC 브라우저 | `ia web start --where local` |
| 밖에서도 (추천) | 이 PC + 같은 Tailscale 계정으로 로그인한 휴대폰·노트북 (LTE 포함) | `ia web start --where tailscale` |
| 같은 Wi-Fi | 집·사무실 같은 네트워크의 기기 | `ia web start --where lan` |

**밖에서 보기 (Tailscale)** — 공개 인터넷에 열지 않고 내 기기끼리만 연결하는 무료 사설망입니다.
1. PC: https://tailscale.com/download 에서 설치 → 로그인
2. 휴대폰: 앱스토어/플레이스토어에서 **Tailscale** 설치 → 같은 계정으로 로그인 → 연결 켜기
3. Claude 에게 "검토 화면 밖에서도 보게 해 줘" (또는 `ia web start --where tailscale`)
4. 알려 준 주소(`http://<PC이름>.<…>.ts.net:8765/`)를 휴대폰에서 열고 **접속 코드**를 한 번 입력 → 30일 동안 로그인 유지

- 접속 코드는 비밀번호처럼 다루세요. 코드를 아는 사람은 업로드 버튼도 쓸 수 있습니다. 바꾸기: `ia web code --reset` (다른 기기는 다시 로그인)
- PC 가 켜져 있어야 열립니다. 아침 예약 작업이 검토 화면도 함께 켭니다. 끄기: `ia web stop`, 상태: `ia web status`
- 방식 C(직접 게시)는 검토 화면에서 **영상 받기 → 인스타 앱으로 올리기 → 캡션 복사 → 게시 주소 입력**까지 휴대폰만으로 할 수 있습니다.
- 방식 A(브라우저)는 업로드 버튼이 "승인"까지만 하고, 실제 게시는 PC 의 Claude 가 합니다 — 채팅에 "승인한 거 올려줘".

## 3-2. 사진은 어디서 오나

저작권이 확인되는 곳에서만 찾습니다: 내 라이브러리 → 공공누리 1유형(파일별 확인) → Wikimedia Commons → Flickr CC(Openverse) → Unsplash·Pexels(무료 키 등록 시).
언론사 사진, 정책브리핑·부처 누리집 사진(사진은 제3자 저작권인 경우가 많음), 정부 홍보 계정 사진은 쓰지 않습니다.
검색 결과는 **사안 관련도순**으로 보여 주고, 맞는 사진이 없으면 사진 없는 C 템플릿으로 만듭니다.
검토 화면의 **사진 더 찾기** 칸에 검색어를 넣어 직접 더 찾을 수도 있습니다(영어 검색어가 더 많이 찾습니다).
Unsplash·Pexels 키 등록(무료, 추천): 터미널에서 `python <플러그인>/scripts/ia.py setup_account set-key unsplash`

## 4. 카테고리

시사·정치, 경제, IT·테크, 연예·엔터, 스포츠, 부동산(뉴스형) / 재테크, 건강·운동, 생활정보, 여행·맛집, 커리어·직장(정보형) / 연애·관계(공감형).
목록과 기본값(소스, 팔레트, CTA, 리스크 안내)은 규칙 서버에서 옵니다. 서브 카테고리는 수집 소스와 트렌드 키워드만 더해집니다.

## 5. 업로드 방식과 주의점

| 방식 | 셋팅 | 어떻게 |
|---|---|---|
| **A. 브라우저** (기본) | 없음 | 내 PC 브라우저에 로그인된 인스타그램 웹에서 Claude 가 만들기 → 파일 → 캡션 → 공유. 매번 **로그인된 계정이 대상 계정인지 확인**하고, 다르면 멈춥니다 |
| **B. API** (고급) | Meta 개발자 앱 + 토큰, 임시 공개 URL | 공식 Instagram API 로 게시. 비즈니스/크리에이터 계정 필요. 예약 게시 가능. 토큰은 OS 키체인에 저장, 만료 7일 전 자동 갱신 |
| **C. 수동** | 없음 | 파일·복사용 캡션·체크리스트만 준비. 직접 올린 뒤 URL 만 알려 주면 기록 |

- **자동화된 방식의 게시는 인스타그램 약관·자동화 탐지 대상이 될 수 있습니다.** 본인 판단으로 사용하세요. 걱정되면 B 나 C 를 쓰세요.
- 업로드 직전에 대상 계정·첫 화면·캡션 전체·방식·예정 시각과 확인표(9항목)를 보여 드리고, **`업로드` 라고 입력해야만** 올립니다. "네", "OK" 로는 올라가지 않습니다.
- 리허설: "드라이런으로 해 줘" → 방식 A 는 캡션 입력 직전에 멈추고, 방식 B 는 계정·한도·토큰 확인까지만 합니다.
- 같은 계정은 30분, 계정 간 5분 이상 간격(규칙 서버 기준), 한 번에 한 게시물, 사람 속도로 진행합니다.
- 방식 B 참고: Instagram 로그인 방식 API 는 PC 의 파일을 직접 받지 않아(2026-11-19 Meta 문서 기준), 영상을 잠시 공개 URL(시놀로지 공개 폴더 또는 S3·R2)에 올렸다가 게시 직후 지웁니다.

## 6. 계정 여러 개 — 일괄 승인 응답 문법

계정이 2개 이상이면 4번의 라운드로 묶어서 묻습니다. 계정은 **별칭**으로, 게시물은 **별칭+번호**로 부릅니다.
항목 사이는 `/` 또는 줄바꿈, 항목 안 값은 쉼표.

| 라운드 | 보여 드리는 것 | 응답 예 |
|---|---|---|
| R1 이슈 | 전 계정 아침 브리핑 | `시사: 1,3,5 / 연애: 2,4` · `시사: 없음` |
| R2 훅·사진 | 게시물별 훅 3버전 + 사진 후보 | `시사1: 강력, 사진2 / 연애2: 순화, C` · `시사3: 보통, l1=직접 쓴 문장, 사진1` |
| R3 결과물 | 카드·그리드·릴스·캡션 | `OK` · `시사1 OK / 연애2 캡션 둘째 줄 삭제` |
| R4 업로드 | 계정 × 게시물 × 방식 × 시각 표 | `업로드` · `업로드: 시사1, 연애2` · `연애2 보류하고 업로드` |

- 어느 라운드든 `전체 추천대로`(★ 그대로), `보류`, `시사3: 보류` 를 쓸 수 있습니다. **R4 만은 `업로드` 라고 써야 합니다.**
- 일부만 답하면 답한 것만 진행하고 나머지만 다시 묻습니다. 애매한 부분은 추측하지 않고 그 부분만 되묻습니다.
- PC 에서는 `output/<날짜>/review.html` 로 전 계정을 한 화면에서 볼 수 있습니다.

## 7. 매일 아침 예약 작업

셋팅 마법사 마지막에 Claude 데스크톱 앱의 **예약 작업**(기본 07:30)을 등록하면, 메인 PC 가 매일 규칙을 받고 전 계정 추천을 만들어
R1 브리핑에서 멈춥니다. 폰에서 그 세션을 열어 이어서 답하면 됩니다. 규칙 서버·뉴스 소스 장애, 토큰 만료 같은 문제는 브리핑 맨 위에 적힙니다.
메인 PC 가 켜져 있고 앱이 실행 중이어야 합니다.

## 8. 저작권·초상권·명예훼손 주의

- 사진은 **내 라이브러리 → 공공누리 제1유형 → Wikimedia Commons(CC0·CC BY·CC BY-SA) → Unsplash/Pexels** 에서만 고릅니다. 언론사·통신사 사진, 일반 이미지 검색 결과는 쓰지 않습니다.
- **공공누리 유형**: 1유형(출처표시)만 씁니다. 2유형(상업적 이용 금지)·3유형(변경 금지)·4유형(둘 다)은 카드에 크롭·글자를 얹는 순간 조건을 어기므로 쓰지 않습니다.
- 실존 인물은 공적 활동 장면만, 미성년자·일반인 얼굴·수사 중인 인물 사진은 피합니다.
- 기사 문장을 베끼지 않고(연속 어절 검사), 팩트 시트에 없는 내용·지어낸 인용·확정되지 않은 범죄 단정은 쓰지 않습니다.
- 최종 책임은 게시하는 계정 주인에게 있습니다. 확인표에 ❌ 가 있으면 올리지 않습니다.

## 9. beta 채널 (새 규칙 먼저 받기)

규칙은 beta 에 먼저 배포된 뒤 stable 로 승격됩니다. 먼저 받아 보려면:

```bash
python "<플러그인 폴더>/scripts/ia.py" setup_account init --channel beta
```

되돌리려면 `--channel stable`. 채널을 바꿔도 진행 중인 작업은 시작할 때의 규칙 버전으로 끝까지 진행합니다.
